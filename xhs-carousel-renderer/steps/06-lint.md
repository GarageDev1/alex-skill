# 第五步：风格自查

运行机械风格检查：

```bash
python "<skill-dir>/scripts/lint.py" <input.md>
```

脚本检测以下规则：

- 正文中是否出现"你"字
- kicker 是否使用了带主观判断色彩的词（解读、深度分析、研判、点评）
- 是否使用了僵硬的中文编号结构（一、二、三）作为主要组织方式
- 每个 section 的数字密度是否过高（建议不超过约3个）
- 正文中是否出现了 H1 标题（标题只属于封面）
- 风险相关内容是否在 `:::risk` 指令外面

脚本只报告发现，不做决策。根据报告的问题修改 Markdown，修改后重新运行验证（第四步）和本步骤，直到满意为止。
